# Changelog

## 0.1.1 - 2026-10-18

- Reject invalid calendar dates instead of accepting any eight digits.
- Return a readable error when the audited workflow file is missing.
- Recognize `python`, `python3`, and `python.exe` command forms.
- Improve cross-platform and legacy workflow audit coverage.

## 0.1.0 - 2026-10-18

- Added the `reproducible-project-runner` agent-neutral workflow project.
- Removed machine-specific runtime defaults from the release copy.
- Added runtime configuration, generic-agent instructions, Codex adapter separation, smoke tests, and GitHub release metadata.
- Excluded Python bytecode and local artifacts from release content.
